One one-star review, written in sap: a houseplant reviews the human who
owns it. It bled sap for three weeks straight, the owner called it
character, then repotted it into a mug with no drainage and a sticker
that says LIVE LAUGH LEAF.

## Run it

```sh
node main.ts
```

Writes the review to `/output/entry.txt` (159 characters, UTF-8, one line).
